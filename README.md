Ідея:
Я створюю програму на тему «Онлайн-бібліотека». Для опису книги я створив окремий клас Book. Цей клас зберігає основну інформацію про книгу: її назву, автора та рік видання.

Мета класу:
Мета класу Book — описати об'єкт книга та зберігати його дані. Також клас дозволяє отримувати інформацію про книгу та змінювати рік її видання з перевіркою правильності даних.

Як створювався клас
Спочатку я створив клас:
public class Book {

Потім додав поля. Я зробив їх private, щоб реалізувати принцип інкапсуляції:
private String title;
private String author;
private int year;

title — назва книги;
author — автор книги;
year — рік видання.

Після цього створив конструктор, який дозволяє одразу задати значення цих полів:
public Book(String title, String author, int year) {
this.title = title;
this.author = author;
this.year = year;
}

Далі я створив методи get, за допомогою яких можна отримати значення закритих полів:
public String getTitle() {
return title;
}

Також:
public String getAuthor() {
return author;
}

public int getYear() {
return year;
}

Для зміни року я створив метод setYear(). У ньому виконується контроль зміни даних:

public void setYear(int year) {
if (year > 0 && year <= 2026) {
this.year = year;
}

Тобто програма перевіряє, чи є рік правильним. Якщо значення більше 0 і не перевищує 2026, воно змінюється.
